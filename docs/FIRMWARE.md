# 升级包由使用者另行提供

[English](FIRMWARE_EN.md)

本仓库和所有公开安装包**不提供固件 BIN、FWUP、固件源码 ZIP 或固件 manifest**。本地开发目录中即使存在这些文件，发布清单和打包脚本也不会将它们包含进去。

配置 LinuxCNC 不需要重新刷写 SD 或 Mesa 固件。桌面软件的维护客户端保留，但升级包必须由使用者从可信提供者另行取得，并确认适用于实际型号、Boot 和业务版本。软件不会下载或自动刷写固件。

升级页默认不选择任何文件。更换目标型号会清除之前的升级包选择，避免继续沿用其他型号文件。未选择升级包时，软件拒绝开始升级，不连接硬件。

- `.fwup`：维护客户端可以校验的应用升级包。
- `.bin`：原始 MCU 镜像，与 `.fwup` 不等价；本软件不在安装时烧录它。

维护前退出 LinuxCNC/HAL 的板卡占用，核对型号、包和恢复方法。主卡读取成功、校验通过或维护握手成功不等于业务应用已通过现场验证。

软件自检用合成且不可执行的数据测试包解析器，不需要任何真实固件文件，也不连接板卡。
