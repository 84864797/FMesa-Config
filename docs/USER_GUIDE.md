# 使用说明

[English](USER_GUIDE_EN.md)

## 安装与启动

安装步骤见 README。普通界面从应用菜单打开或运行 `fmesa-config`；源码版运行 `bash run.sh`。不需要 sudo。桌面应用不自动连接硬件、不自动启动 LinuxCNC。

## 配置顺序

1. **基本信息**：工程名、XYZ/XYZA/XYZAB 等轴布局与伺服周期。线性轴单位为 mm，旋转轴为 degree。
2. **操作界面**：AXIS、Gmoccapy、QtDragon/HD、Probe Basic。Probe Basic 需另行安装并选择官方模板，详见 [PB说明](PROBE_BASIC.md)。目标 LinuxCNC 电脑需安装对应界面。QtDragon 模板目前限 XYZ/XYZA。
3. **硬件发现**：选择 F7I92 或自定义，填写板卡 IP。自定义板卡须读取固件资源后分配功能。发现的是固件可用通道，不是强制新增机床轴。
4. **轴**：设置 StepGen 通道、每单位脉冲数、速度、加速度、行程、回零偏置与搜索/锁存速度。脉冲数不能为 0，各轴不能重复占同一 StepGen。
5. **输入输出**：主卡页和自定义引脚页分配 GPIO。启用 SD 后在同一页签组出现从板配置；输入可选反向。不要把固件占用的 StepGen/PWM/编码器引脚另设为普通 GPIO。
6. **主轴**：模拟量使用板卡 PWM→0–10V 电路；F7I92 固定 PWM0。当前新工程默认 PWM 反向、200Hz。伺服类型使用独立 StepGen，填写每转脉冲数、RPM、加速度与脉冲时序。
7. **手轮 MPG**：选 3/4/5 轴。固定 VGA 接口对应编码器00，IO25/23/21/22/24 选 X/Y/Z/A/B，IO28/20 选倍率；IO29 作为普通输入在本页配置。
8. **预览导出**：先处理错误，再选择新目录。工具不覆盖已有配置目录。最后通过 LinuxCNC 打开目录中的 INI。

## F7I92 固定规则

- IO0：固定输出、反向，模拟主轴默认正转；伺服主轴不显示/不生成该正转输出。
- IO2/3：固定输出、反向，在输入输出页分配功能。
- IO14～19：固定输入，可选择输入反向。
- IO1：PWM0，由主轴页设置反向，不作为普通输入输出分配。
- IO30～33：自定义引脚页可读取实际固件功能。发现为轴 Step/Dir 时在轴页配置；智能串口同样取决于实际 TX/RX 固件功能。

这些是当前 F7I92 产品规则，不应直接套到其他板卡。自定义引脚的功能改变需要先刷入相应 FPGA 固件。

## 急停

与 PNCconf 的普通生成分支一致：分配外部急停允许输入时，该输入 TRUE 允许解除急停、FALSE 保持急停。是否反向应按实际常开/常闭接线确定。没有配置有效外部急停输入时，生成软件急停回路。没有单独的急停模式下拉选项。

## 保存与重新导出

“保存工程”保存 JSON；“导出”保存 LinuxCNC 运行文件及 JSON。修改 JSON 不会改变正在运行的 LinuxCNC，修改向导也不会自动更新已经导出的目录。需重新导出到新目录，关闭旧实例并由操作者重新加载配置。

## 常见问题

- **Qt xcb 插件/缺共享库**：用终端启动查看完整缺库名；优先 apt 安装 `.deb` 以补齐依赖。不可用任意路径的其他 Qt 插件替换捆绑插件。
- **mesaflash 找不到**：在目标电脑安装 mesaflash，确认终端可运行 `mesaflash --help`。
- **发现失败**：检查本机网口、IP、子网和板卡供电；读取结果必须与安装的固件一致。
- **Smart Serial 扫描超时**：主卡读取成功不代表从板通信成功。退出 LinuxCNC 后再扫描，检查电源、TX/RX、通道、业务固件和串口模式。Boot 维护状态不等于业务应用。
- **解除急停失败**：检查导出的 HAL 和实际输入状态；不要把错误提示中的“外部急停已设置”当作已经成功分配了急停输入。
- **主轴转速不对**：核对满量程 RPM、PWM 频率和反向选项；与已有可用配置逐项比较，不以变量名称相同代替电气验证。

## 只读通信监控

Debian 安装版运行 `fmesa-monitor`，源码版运行 `bash run_monitor.sh`。需要系统 Python 的 LinuxCNC `hal` 模块及 `python3-tk`；它不使用应用捆绑的 Python，不写板卡或 HAL 参数。与固件升级是两个不同功能。

## 0.3 高级机床配置（测试版）

- 基本信息页：要求回零、恢复位置、单独回零、换刀时主轴运行/Z抬升/随机刀库、MDI命令、编辑器、图像与Python过滤器。默认仍要求回零，默认不恢复旧位置。
- 轴页“反馈、补偿与双驱”：Step/Dir或PWM模拟伺服、独立编码器与索引回零、PID参数、反向间隙或补偿表、第二电机StepGen/比例/回零开关位置。补偿表在导出时复制到配置目录。
- 双驱按X、Y、第二Y、Z等顺序编号关节；启用/关闭时保留已有输入输出所对应的电机，并更新关节编号；仍应按IO下拉中的关节号核对接线。两个电机必须各分配一个独立回零输入，生成负HOME_SEQUENCE同步回零和trivkins kinstype=BOTH。第二电机继承主电机的速度、时序和PID，脉冲当量与开关位置单独填写；当前第二电机使用Step/Dir。
- 模拟伺服轴需要可用PWM和独立编码器、输出比例、明确的PID增益及最大输出；F7I92固定PWM0留给主轴，因此此项只适用于具备相应资源的自定义板卡。
- 主轴页“编码器与PID”：编码器每转计数、速度闭环、PID及到速容差。编码器比例使用四倍频后的计数，不直接等于编码器铭牌线数。编码器不能与手轮/轴共用。关闭反馈时保留原开环模式；开启后speed-in/revs/index-enable来自真实编码器，Step/Dir闭环将RPM转换为rev/s。同步加工还需要实际Index接线及相应机床支持，生成连接不代表已完成同步攻丝验收。
- 编码器索引回零必须有对应Index引脚和回零开关。补偿启用后，StepGen最大速度及加速度余量按PNCconf增至2倍。
- 默认值及生成规则已对照本机LinuxCNC 2.9 PNCconf源码，并做离线组合测试；没有进行机床运动、闭环整定或实机启动验证。高级功能请按实际硬件填写和调试。Probe Basic仍使用官方模板的手动换刀配置，不生成ATC或主轴定向。
